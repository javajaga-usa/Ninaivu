# Reading the words in photographs — signs, menus, screenshots, the back of a
# postcard — so they can be searched for.
#
# Easiest: the console, Settings → Extras → "Reading the words in photographs".
#
# By hand, into Ninaivu's own virtual environment, in two steps:
#
#   pip install -r requirements/requirements-ocr.txt
#   pip install --no-deps "rapidocr>=3,<4"
#
# rapidocr asks for `opencv-python`; Ninaivu already has
# `opencv-python-headless`, the same `cv2` built without a window system.
# Installing rapidocr with its own list puts a second OpenCV over the first —
# which fails on Windows while Ninaivu has cv2 loaded, and elsewhere leaves
# two packages owning one folder. So this file is rapidocr's own list less
# OpenCV (the same list the console installs, media/components.py), and
# rapidocr itself goes in without its list.
#
# The models ship inside the wheel — about 32 MB — so nothing is downloaded
# when Ninaivu runs and nothing about the picture leaves the machine.
#
# Then turn it on:  --ocr   (or on the AI models page)
pyclipper>=1.4.0
numpy>=2.5.3,<3
six>=1.15.0
Shapely!=2.0.4,>=2.1.2
PyYAML
Pillow
tqdm
omegaconf!=2.2.1
requests
colorlog
