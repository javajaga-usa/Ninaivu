# வெளியிலிருந்து அணுகுதல்

வீட்டில், நினைவு வீட்டு network-இல் ஒரு பெயருக்குப் பதில் அளிக்கிறது (`ninaivu.local`).
வீட்டை விட்டு வெளியே இருக்கும்போது, குடும்பம் அமைத்த ஏதோ ஒன்றின் வழியாக அதை
அடையலாம் — *எப்படி* என்பதை நினைவு ஒரு தேர்வாகக் கருதுகிறது; அது
**System → Server → Away from home** பக்கத்தில் ஒருமுறை செய்யப்படுகிறது.

| தேர்வு | அது என்ன | அதற்கு என்ன தேவை |
| --- | --- | --- |
| **Tailscale** | உங்கள் சொந்தச் சாதனங்களுக்கு இடையே ஒரு தனிப்பட்ட network; மிக எளிதானது | server-இலும் ஒவ்வொரு கைப்பேசியிலும் Tailscale நிறுவியிருக்க வேண்டும் |
| **WireGuard** | அதே யோசனை, கையால் அமைக்கப்படுவது | tunnel, அதன் subnets இங்கே தட்டச்சு செய்யப்பட வேண்டும் |
| **A tunnel** | Cloudflare Tunnel போன்றவை: வீட்டை அடையும் ஒரு பொதுப் பெயர் | tunnel, அந்தப் பெயர் இங்கே தட்டச்சு செய்யப்பட வேண்டும் |
| **Your own reverse proxy** | முன்னால் Caddy அல்லது nginx, ஒரு சான்றிதழுடன் | அந்த proxy ([உதாரணங்கள்](../../operations/production.md)) |
| **Nothing** | வீட்டு network மட்டும் | — |

கணினியில் Tailscale இருந்தால், இயல்புநிலை அதைத் தானாகவே கண்டுபிடித்துக்கொள்ளும்.

ஒவ்வொரு தேர்வும் தனக்கு இன்னும் என்ன தேவை என்று சொல்கிறது; எந்த முகவரிகள்
*வீட்டுக்கு வெளியே* எனக் கருதப்பட வேண்டும், குடும்பத்துக்கு எந்த முகவரிகள்
பட்டியலிடப்பட வேண்டும், யாருடைய சான்றிதழ் (certificate) வழங்கப்பட வேண்டும் என்பதையும்
அதுவே தீர்மானிக்கிறது.

## HTTPS

நினைவு தனக்கென ஒரு certificate authority-ஐ உருவாக்கி, அதைக் கொண்டு HTTPS வழங்குகிறது.
எச்சரிக்கை காட்டக் கூடாத ஒவ்வொரு சாதனமும் அந்தச் சான்றிதழை ஒருமுறை நம்ப (trust)
வேண்டும்; அதற்கான பொத்தான் tray-இலும் நிர்வாக பலகையின் Server பக்கத்திலும் உள்ளது.
Windows, macOS-க்கான விவரங்கள் [tray பக்கத்தில் (ஆங்கிலம்)](../../desktop-control.md).
Tailscale-உம் reverse proxy-உம் தங்கள் சொந்தச் சான்றிதழ்களைக் கொண்டு வருகின்றன.

## மற்ற சாதனங்களிலிருந்து நிர்வாக பலகை

குடும்பச் செயலி முழு வீட்டு network-க்கும் பதில் அளிக்கிறது; Server பக்கத்தில்
*Open this console from other devices at home too* என்பதைத் தேர்ந்தெடுக்கும் வரை
**நிர்வாக பலகை இந்தக் கணினியில் மட்டுமே பதில் அளிக்கும்** (அப்போது நினைவு restart
ஆகும்). `--admin-host` அதன் முகவரியை நேரடியாக அமைக்கிறது.

## நினைவு தானாக வெளியே அனுப்புபவை அனைத்தும்

வெளியிலிருந்து அணுகுதல் என்பது வீட்டுக்குள் *வரும்* ஒரு வழி மட்டுமே. அதன் மூலம்
முகங்கள், பெயர்கள், புகைப்படங்கள் எங்கும் ஒருபோதும் அனுப்பப்படுவதில்லை. அந்த
நேரத்தில் யாரும் எதையும் அழுத்தாமல், நினைவு இணையத்திடம் கேட்பவற்றின் முழுப் பட்டியல்
இதுதான்:

| எது | எப்போது | எப்படி நிறுத்துவது |
| --- | --- | --- |
| GitHub-இன் releases பக்கத்துக்கு ஒரு கோரிக்கை: புதிய பதிப்பு உள்ளதா? இந்தக் கணினியைப் பற்றி எதுவும் அதில் இல்லை. | நாளுக்கு ஒருமுறை | **Server** → update check |
| முகில்: புகைப்படங்களும் அட்டவணையின் தினசரி நகலும், மறையாக்கப்பட்டு, நீங்கள் இணைத்த Google கணக்குக்கு | முகில் இயக்கத்தில் இருக்கும் வரை | **Mugil** |
| இந்தக் கணினிக்கான Tailscale-இன் HTTPS சான்றிதழ், Tailscale வழியாக | HTTPS இயக்கத்திலும் Tailscale நிறுவப்பட்டும் இருந்தால், சில வாரங்களுக்கு ஒருமுறை. அப்போது `<computer>.<tailnet>.ts.net` என்ற பெயர், ஒவ்வொரு Let's Encrypt பெயரையும் போலவே, பொதுச் சான்றிதழ் பதிவுகளில் தோன்றும். | **Advanced settings** → `tailnet_https` |
| image model-இன் weights, Hugging Face-இலிருந்து | விவரித்துத் தேடுதல் சேர்க்கப்பட்ட பின் முதல் தொடக்கத்தில் ஒருமுறை; அதன் பிறகு எதுவும் இல்லை | விவரித்துத் தேடுதலைச் சேர்க்காதீர்கள் |
| பாதியில் நின்ற ஒரு model பதிவிறக்கம் | அடுத்த தொடக்கத்தில், முடியும் வரை | **AI models** |
| இடங்களின் பட்டியல், GeoNames-இலிருந்து | *Name the places* இயக்கப்பட்ட பின் முதல் ஸ்கேனில் ஒருமுறை | அதை அணைத்தே வையுங்கள் |
| OpenStreetMap-இலிருந்து வரைபட tiles — உங்கள் புகைப்படங்கள் ஏறக்குறைய எங்கே எடுக்கப்பட்டன என்பதை அவை காட்டும் | `map_tiles` இயக்கத்தில் இருந்தால், யாராவது வரைபடத்தைத் திறக்கும்போதெல்லாம் (இயல்பாக அணைந்திருக்கும்; இல்லையெனில் வரைபடம் உள்ளமைந்த ஒரு வெளிக்கோட்டைப் பயன்படுத்தும்) | **Advanced settings** → `map_tiles` |

Model பதிவிறக்கங்கள், email அல்லது webhook மூலம் அறிவிப்புகள், Gemini போன்ற நீட்சிகள்
ஆகியவை ஒரு நிர்வாகி அவற்றை அமைத்த பின்னரே நடக்கும்.
