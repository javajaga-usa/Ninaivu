# நினைவு

**நினைவு** (Ninaivu) — உங்கள் குடும்பப் புகைப்படங்கள், உங்கள் வீட்டிலேயே.

நினைவு என்பது ஒரு குடும்பத்துக்கான தனிப்பட்ட புகைப்பட, காணொளி நூலகம். நீங்களே
வைத்திருக்கும் ஒரு கணினியில் இது இயங்குகிறது; உங்கள் சொந்த வட்டுகளில் (disks)
உள்ளவற்றை அட்டவணைப்படுத்துகிறது (index). பொதுவாக மக்கள் ஒரு cloud சேவையிடம்
ஒப்படைக்கும் வசதிகளை இது உங்கள் குடும்பத்துக்கே தருகிறது: முகங்களும் பெயர்களும்,
விவரித்துத் தேடுதல், வரைபடத்தில் இடங்கள், "இதே நாளில்" நினைவுகள், தாத்தா பாட்டிக்கு
ஒரு பகிர்வு இணைப்பு, தங்கள் புகைப்படங்களை வீட்டுக்கே அனுப்பும் கைப்பேசிகள்.
நீங்கள் தேர்ந்தெடுக்காத இடத்துக்கு எதுவும் வீட்டை விட்டு வெளியே போவதில்லை —
காப்புப்பிரதியும் மறையாக்கம் (encryption) செய்யப்பட்டே போகிறது.

![படத்தொகுப்பு](../../screens/family-gallery.jpg)

இதற்கு மூன்று பகுதிகள் உண்டு; ஒவ்வொன்றுக்கும் ஒரு பெயர்:

| | |
| --- | --- |
| **நினைவு** (Ninaivu) | நூலகம்: படத்தொகுப்பு, முகங்கள், தேடல், இடங்கள், ஆல்பங்கள், பகிர்வு, மூன்று பங்குகள் (roles) |
| **முகில்** (Mugil) | காப்புப்பிரதி: நூலகத்தின் மறையாக்கப்பட்ட நகல் Google Drive-இல்; வீட்டுக் கைப்பேசிகள் தங்கள் புகைப்படங்களை வீட்டுக்கே அனுப்புதல் |
| **சுடர்** (Sudar) | புகைப்பட ஸ்டுடியோ: ஒளி, நிறம், நேராக்குதல், வெட்டுதல் (crop), பரிந்துரைகள் — உலாவியிலேயே; மூலப் படம் ஒருபோதும் மாறாது |

## நினைவு லைட்

**[நினைவு லைட் (Ninaivu Lite)](https://github.com/javajaga-usa/Ninaivu-lite)** —
வீட்டு Wi-Fi-இல் குடும்பப் படத்தொகுப்பை எளிதாகப் பார்க்க விரும்புபவர்களுக்கான
சிறிய பதிப்பு. நினைவின் அதே குடும்பப் படத்தொகுப்பு, நிர்வாக பலகை, பகிர்வுத்
திரைகள் தமிழிலும் ஆங்கிலத்திலும் உள்ளன. மூலப் புகைப்படங்கள் மாற்றப்படுவதில்லை.

| நினைவு லைட் | முழு நினைவு பதிப்பு |
| --- | --- |
| காலவரிசை, கோப்புறைகள், பிடித்தவை, ஆல்பங்கள்; பெயர், கோப்புறை, தேதி, கேமரா மூலம் தேடல் | முகங்களை அடையாளம் காணுதல், விவரித்துத் தேடுதல், வரைபடத்தில் இடங்கள் |
| நிர்வாகி, குடும்பம், விருந்தினர் பங்குகள்; தெரிவுநிலை; கடவுச்சொல்லுடன் பகிர்வு இணைப்புகள் | முழு நூலகம், முகில் cloud காப்புப்பிரதி, கைப்பேசி காப்புப்பிரதி |
| பழைய வட்டுகளிலிருந்து சரிபார்த்து இறக்குமதி; உலாவியில் சுடர் புகைப்படத் திருத்தம் | AI மாதிரிகளைப் பயன்படுத்தும் கருவிகள், முழு சுடர் ஸ்டுடியோ |
| Flask, Pillow, waitress ஆகிய மூன்று சார்புகள் கொண்ட இலகுவான இயந்திரம் | பெரிய இயந்திரத்தையும் விருப்ப AI மாதிரிகளையும் இயக்கக்கூடிய கணினி |

லைட்டில் AI மாதிரிகள், cloud காப்புப்பிரதி, கைப்பேசி காப்புப்பிரதி இல்லை.
Windows 10+, macOS, Linux மற்றும் 64-bit OS கொண்ட Raspberry Pi 4/5-இல் இயங்கும்.
நிறுவிகள் Python-ஐ உடன் கொண்டுள்ளன; Windows portable zip, Docker முறையும் உண்டு.

- **[லைட்டைப் பதிவிறக்க](https://github.com/javajaga-usa/Ninaivu-lite/releases/latest)** —
  உங்கள் கணினிக்கான நிறுவியைத் தேர்ந்தெடுக்கவும். வெளியீடுகள் தற்போது code-sign
  செய்யப்படவில்லை; [நிறுவல் குறிப்புகளைப்](https://github.com/javajaga-usa/Ninaivu-lite#install) பார்க்கவும்.
- **[தமிழ் வழிகாட்டி](https://github.com/javajaga-usa/Ninaivu-lite/blob/main/docs/USER-GUIDE.ta.md)**
  · **[English guide](https://github.com/javajaga-usa/Ninaivu-lite/blob/main/docs/USER-GUIDE.md)**.
- **[லைட்டிலிருந்து நினைவுக்கு மாறுதல்](https://github.com/javajaga-usa/Ninaivu-lite/blob/main/docs/UPGRADE.md)** —
  பின்னர் பெரிய பதிப்பு தேவைப்பட்டால் மட்டும் (ஆங்கிலத்தில்).

லைட் HTTP-ஐப் பயன்படுத்துகிறது; வீட்டு நெட்வொர்க்குக்கு மட்டும்.
இணையத்துக்கு நேரடியாகத் திறக்க வேண்டாம். இந்தத் தளத்தின் மற்ற பக்கங்கள்
முழு நினைவு பதிப்பைப் பற்றியவை; லைட்டின் அமைப்பு, காப்புப்பிரதி, மீட்புக்கு
மேலே உள்ள லைட் வழிகாட்டியைப் பயன்படுத்தவும்.

## எங்கிருந்து தொடங்குவது

1. [நிறுவுதல்](install.md) — Windows, macOS, Linux அல்லது Raspberry Pi-க்கான நிறுவி. பத்து நிமிடங்கள்.
2. [முதல் நாள்](first-day.md) — கோப்புறை, குடும்பத்தினர், ஸ்கேன் தானாகக் கண்டுபிடிப்பவை.
3. [குடும்பமும் பங்குகளும்](family-and-roles.md) — யார் எதைப் பார்க்கலாம்.
4. [காப்புப்பிரதி](backup.md) — வீட்டுக்கு வெளியே ஒரு நகல், ஒவ்வொரு வாரமும் சோதிக்கப்படுவது.
5. [வெளியிலிருந்து அணுகுதல்](remote-access.md) — வீட்டை விட்டு வெளியே இருக்கும்போது.
6. [AI](ai.md) — உங்கள் கணினியில் என்ன இயங்குகிறது, சிறிய கணினி எதைத் தவிர்க்கிறது.
7. [சிக்கல் தீர்த்தல்](troubleshooting.md).

அதன் பிறகு **வழிகாட்டி** — ஒவ்வொரு திரையும் என்ன செய்கிறது என்பது முழுவதும்:
குடும்பத்தினருக்கு [குடும்பச் செயலி](guide-family.md), அதை நடத்துபவருக்கு
[நிர்வாக பலகை](guide-console.md). எல்லாத் திரைகளும் படங்களுடன்:
[திரைகளின் சுற்றுலா](../../screens.md) (ஆங்கிலத்தில்).

!!! note "தற்போதைய நிலை"
    நினைவு 0.1.0 என்பது, ஒரு குடும்பத்தின் நூலகத்தை ஓராண்டாக இயக்கி வந்த ஒரு
    server-இன் பொதுப் பதிப்பு. இதில் ஏறக்குறைய 3,500 சோதனைகள் (tests) உள்ளன.
    1.0-க்கு இன்னும் என்ன தேவை என்பதை [roadmap](../../ROADMAP.md) சொல்கிறது.

!!! tip "இந்த வழிகாட்டியைப் பற்றி"
    கட்டளைகள் (commands), கோப்புப் பெயர்கள், விசைகள் (keys), அமைப்புகளின் பெயர்கள்
    ஆங்கிலத்திலேயே உள்ளன — திரையிலும் terminal-இலும் நீங்கள் தட்டச்சு செய்வது அவைதான்.
    குடும்பச் செயலி தமிழில் பேசும்; அதன் பொத்தான்களின் தமிழ்ப் பெயர்கள் இங்கே
    அப்படியே உள்ளன. நிர்வாக பலகை இப்போதைக்கு ஆங்கிலத்தில் மட்டும் — அதன் பக்கங்களின்
    பெயர்கள் திரையில் தெரிவது போலவே ஆங்கிலத்தில் **தடித்த எழுத்தில்** உள்ளன.
