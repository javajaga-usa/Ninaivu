# AI

இந்தப் பக்கத்தில் உள்ள அனைத்தும் உங்கள் சொந்தக் கணினியிலேயே இயங்குகின்றன; இவற்றில்
எதுவும் எந்தப் புகைப்படத்தையும், முகத்தையும், பெயரையும் எங்கும் அனுப்புவதில்லை. ஒரே
விதிவிலக்கு: நீங்கள் இயக்கும், அதன் switch-இலேயே வேறுவிதமாகச் சொல்லும் ஒரு நீட்சி
(கீழே உள்ள Gemini). Model-கள், அவற்றின் வசதியை நீங்கள் இயக்கும்போது ஒருமுறை மட்டும்
பதிவிறக்கப்படுகின்றன.

## இரண்டு வகைக் கணினிகள்

நினைவு இரண்டு வகைக் கணினிகளில் சோதிக்கப்படுகிறது; உங்களுடையது எந்த வகை என்பதைத்
தொடங்கும்போதே அது கண்டுபிடித்துக்கொள்ளும் (**System → Performance** எது, ஏன் என்று
சொல்லும்):

| | Basic (அடிப்படை) | Full (முழு) |
| --- | --- | --- |
| கணினி | மற்ற எதுவும்: ஒரு mini PC, பழைய laptop, single-board computer, graphics card இல்லாத அல்லது image model இல்லாத desktop | குறைந்தது 6 GB நினைவகம் உள்ள graphics processor, அல்லது Apple silicon, அல்லது விவரித்துத் தேடுதல் சேர்க்கப்பட்ட பின் 8 GB நினைவகம் உள்ள எந்தக் கணினியும் |
| படத்தொகுப்பு, ஆல்பங்கள், பகிர்வு, பங்குகள் | ஆம் | ஆம் |
| முகங்கள், குழுவாக்கி பெயரிடுதல் | ஆம் | ஆம் |
| பக்கவாட்டில் சாய்ந்த புகைப்படங்களைச் சரிசெய்தல் | ஆம் | ஆம் |
| இருப்பிடத்திலிருந்து இடங்களுக்குப் பெயரிடுதல் | ஆம் | ஆம் |
| புகைப்படங்களிலிருந்து எழுத்துகளைப் படித்தல் (text reader உடன்) | ஆம், மெதுவாக | ஆம் |
| பெயர்கள், தேதிகள், இடங்கள், நபர்கள் ஆகியவற்றின் சொற்களால் தேடல் | ஆம் | ஆம் |
| முகில், மறையாக்கப்பட்ட நகல் | ஆம் | ஆம் |
| image model-இலிருந்து குறிச்சொற்கள் (tags), "the beach at sunset" போன்ற தேடல், விவரணைகள் | — | ஆம் |
| பார்வைக்கு ஒத்த புகைப்படங்களைக் கண்டுபிடித்தல் (புகைப்படக் காட்சியில் `S`) | — | ஆம் |
| பல தருணங்களிலிருந்து விவரிக்கப்படும் காணொளிகள் | — | ஆம் |
| Creative Studio: generative திருத்தங்கள், பொருள் நீக்கம், upscaling | — | graphics card உடன் |

Basic கணினியில் *auto* என்றால் light engine; ஆகவே அது பெரிய model-களை ஏற்ற ஒருபோதும்
முயலாது, விரைவாகத் தொடங்கும். Image model-ஐ நேரடியாகத் தேர்ந்தெடுத்தால் (`--ai clip`,
அல்லது **All settings**-இல் `ai_engine`) அது இன்னும் ஏற்றப்படும். **All settings**
பக்கத்தில் `hardware_tier` அமைப்பை மாற்றினால், அளவீட்டை மீறி நீங்கள் சொல்வதே நடக்கும்.

## விவரித்துத் தேடுதலைச் சேர்த்தல்

இது இயல்பாக நிறுவப்படுவதில்லை: ஏறக்குறைய 2 GB, அதோடு model-உம். முதல் நாள்
வழிகாட்டலிலிருந்தோ **Settings → Extras → Search by description**-இலிருந்தோ சேர்த்து,
பிறகு நினைவை restart செய்யுங்கள். Full கணினியில் அதன் பிறகு அது பயன்படுத்தப்படும்;
model-இன் weights அந்த முதல் தொடக்கத்தில் ஒருமுறை மட்டும் பெறப்படும்; அதன் பிறகு model
நூலகங்கள் எந்தக் கோரிக்கையும் செய்யக் கூடாது என்று நினைவு சொல்லிவிடும்
(`HF_HUB_OFFLINE`).

## ஒவ்வொரு சுற்றும் என்ன செய்கிறது

**AI → AI models** பக்கத்தில் ஒவ்வொன்றுக்கும் ஒரு switch உண்டு; அது எந்த model-ஐக்
கேட்கிறது, அந்த model இங்கே இருக்கிறதா என்பதையும் அது சொல்லும்.

- **Faces** (முகங்கள்) — 37 MB கண்டறிவியும் பொருத்தியும். குழுக்களுக்கு **Faces**
  பக்கத்தில் பெயரிடப்படுகிறது; ஒன்றுக்குப் பெயரிட்டால் மற்றவை பின்தொடரும்.
- **Places** (இடங்கள்) — 11 MB இடப் பட்டியல், GeoNames-இலிருந்து ஒருமுறை
  பதிவிறக்கப்படும்; புகைப்படத்தின் சொந்த இருப்பிடம் "Paris" அல்லது "the beach"
  ஆகிவிடும். வரைபடம் உலகின் உள்ளமைந்த வெளிக்கோட்டைப் பயன்படுத்துகிறது;
  OpenStreetMap-இன் தெரு வரைபட tiles, `map_tiles` இயக்கப்படாவிட்டால் அணைந்திருக்கும் —
  ஏனெனில் கேட்கப்படும் ஒவ்வொரு tile-உம் ஒரு புகைப்படம் ஏறக்குறைய எங்கே எடுக்கப்பட்டது
  என்பதைக் காட்டும்.
- **Sideways photographs** (சாய்ந்த புகைப்படங்கள்) — ஒரு புகைப்படம் எந்தப் பக்கம்
  மேலே இருக்க வேண்டும் என்று சொல்லும் 77 MB model. இயல்பாக, ஒவ்வொரு ஸ்கேனுக்குப்
  பிறகும் அது தானாகவே பார்த்து, கண்டுபிடிப்பவற்றை உடனே ஒரே தொகுதியாகத்
  திருப்பிவிடும்; **Review → Straighten**-இல் **Undo** அந்தத் தொகுதியைத் திரும்ப
  வைக்கும். அதை அணைத்தால், அது கண்டுபிடிப்பவை அங்கே ஒப்புதலுக்காகக்
  காத்திருக்கும்.
- **Text in photographs** (புகைப்படங்களில் எழுத்துகள்) — **Extras**-இலிருந்து text
  reader; processor-இல் மெதுவாக இயங்கும்.
- **The image model** (Full, சேர்க்கப்பட்ட பின்) — CLIP அல்லது SigLIP: குறிச்சொற்கள்,
  "the beach at sunset" போன்ற தேடல், விவரணைகள், பார்வைக்கு ஒத்த புகைப்படங்கள்.
- **Videos** (Full) — poster frame-ஐ மட்டும் அல்லாமல், பல தருணங்களிலிருந்து
  விவரிக்கப்படும்.

## சுடர் {#sudar}

**சுடர்** (Sudar) உலாவியிலேயே திருத்துகிறது: ஒளி, நிறம், நேராக்குதல், வெட்டுதல்,
தோற்றங்கள் (looks), படத்திலிருந்தே அளந்து சொல்லப்படும் பரிந்துரைகள். "Make it warmer"
என்று எளிய சொற்களிலும் சொல்லலாம். மூலப் படம் ஒருபோதும் மாறாது; அதன் அருகே ஒரு நகல்
சேமிக்கப்படுகிறது — ஒரு கருவி தரும் எந்த முடிவும் அப்படியே சேமிக்கலாம் (வெட்டி எடுத்த
பொருள், நிறமூட்டிய பழைய படம்); ஒரு குடும்ப உறுப்பினரின் நகல், ஒரு பதிவேற்றம்
போலவே நிர்வாகியின் ஒப்புதலுக்காகக் காத்திருக்கும். **Photo Studio** (படக் காட்சியில்
*Edit photo*) இதே engine-இல்தான் வேலை செய்கிறது; ஆகவே ஒரு slider இரண்டிலும் ஒன்றையே
குறிக்கும். ஒவ்வொரு பகுதியும் [குடும்பச் செயலி வழிகாட்டியில்](guide-family.md).

அதன் **Skin**, **Hair** கருவிகள் புகைப்படத்தில் உள்ள ஒவ்வொரு நபரின் மேலும், அவரவர்
சொந்தத் தோலை வைத்தே மதிப்பிட்டு, **AI models**-இல் உள்ள முக model-ஐக் கொண்டு வேலை
செய்கின்றன. பொட்டு, சிந்தூரம், திருநீறு ஆகியவற்றை இருப்பது போலவே விட்டுவிடும்;
நிறத்தை வெளுக்கும் அமைப்பு எதுவும் இவற்றில் இல்லை. பின்னணியின் நிறத்திலேயே உள்ள
முடி, *Background removal (RMBG-1.4)* model நிறுவப்பட்டிருந்தால் அதன் உதவியுடன்
கண்டுபிடிக்கப்படும்; இல்லையென்றால் கையால் வரைந்து சேர்க்கலாம்; **Add hair** அருகில்
உள்ள இழைகளிலிருந்து புதிய முடியை இந்தக் கணினியிலேயே வரையும்.
[குடும்பச் செயலி வழிகாட்டியைப் பாருங்கள்](guide-family.md#skin-and-hair).

அதன் **Enhance tools** ஒவ்வொன்றுக்கும் ஒரு model தேவை; எது தேவை என்று அந்த அட்டை
சொல்லும்:

- **Upscale** — *Upscale ×4 (Real-ESRGAN)*, **AI models**-இலிருந்து.
- **Restore faces** — *Restore faces (GFPGAN 1.4)*, **AI models**-இலிருந்து.
- **Colourise** — ஒரு DDColor ONNX model. பட்டியல் (catalogue) இதை இன்னும் pin
  செய்ய முடியாது; ஆகவே கையால் வைக்க வேண்டிய ஒரே model இது: `ddcolor.onnx` கோப்பை
  model-கள் கோப்புறையின் `onnx` துணைக் கோப்புறையில் வையுங்கள் (**AI models** அந்தக்
  கோப்புறையைக் காட்டும்), அல்லது `NINAIVU_COLORIZE_MODEL`-ஐ அந்தக் கோப்பை நோக்கி
  அமையுங்கள். Restore faces-உம் இருந்தால், **Revive old photo** இரண்டையும் ஒரே
  தட்டலில் செய்யும்.

ஒவ்வொன்றும் இந்தக் கணினியிலேயே இயங்கும்; எதுவும் வெளியே போகாது. Creative Studio
நீட்சியுடன், இவற்றில் எதையும் ஒரு AI server workflow ஏற்றுக்கொள்ளலாம்.

## நீட்சிகள் (Extensions)

மையத்தின் இரண்டு வாக்குறுதிகளைக் காப்பாற்ற முடியாத எதுவும் — நீங்கள் தேர்ந்தெடுத்த
இடத்தைத் தவிர எதுவும் வீட்டை விட்டுப் போகாது, அது ஒரு சிறிய கணினியில் இயங்கும் —
ஒரு நீட்சி (extension) ஆகும். **System → Settings → Extensions**-இல் இயக்கும் வரை
அது அணைந்தே இருக்கும் (நினைவு அடுத்த முறை தொடங்கும்போது அது அமலுக்கு வரும்); அதன்
switch அது என்ன செய்கிறது என்று சொல்லும்:

- **Creative Studio** — generative திருத்தங்களும், பெரிய model-களுடன் கூடிய கனமான
  கருவிகளும்; GPU உள்ள இந்தக் கணினியிலோ, வீட்டில் உள்ள ஒரு ComfyUI server-இலோ.
  AI server பக்கம் இணையத்தில் உள்ள முகவரியை மறுக்கும், ஆகவே எதுவும் வீட்டை விட்டுப்
  போகாது (Tailscale முகவரி வீடாகவே கணக்கிடப்படும்).
- **Gemini** — Google-இன் model-களிலிருந்து திருத்தங்களும் விவரணைகளும். ஒரு கோரிக்கை
  ஒரு புகைப்படத்தைக் குறிப்பிடும்போது, அப்போது மட்டுமே, அதன் மறுகுறியாக்கப்பட்ட
  (re-encoded) நகல் Google-க்குச் செல்லும். Settings → Extensions கீழ் *Let family
  members send photographs to extensions that go outside the house* தேர்ந்தெடுக்கப்படாவிட்டால்,
  ஒரு நிர்வாகி மட்டுமே அனுப்ப முடியும்.

நீட்சிகளை அமைப்பது [தொழில்நுட்ப நிர்வாகி வழிகாட்டியில்](../../admin-guide.md) உள்ளது (ஆங்கிலத்தில்).
