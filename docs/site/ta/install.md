# நிறுவுதல்

எப்போதும் இயங்கிக்கொண்டிருக்கும் ஒரு கணினியில் நினைவு இயங்குகிறது: படிக்கட்டுக்குக்
கீழே ஒரு desktop, ஒரு mini PC, ஒரு பழைய laptop, ஒரு Mac mini, ஒரு Raspberry Pi.
அந்தக் கணினிக்கான நிறுவியை (installer) பதிவிறக்கி இயக்குங்கள். நினைவுக்குத்
தேவையான அனைத்தையும் அது தன்னுடனேயே கொண்டு வருகிறது; முதலில் வேறு எதையும் நிறுவ
வேண்டியதில்லை.

## பதிவிறக்கம்

நிறுவிகள் நினைவின் பதிவிறக்கப் பக்கத்தில் உள்ளன:
[github.com/javajaga-usa/Ninaivu/releases/latest](https://github.com/javajaga-usa/Ninaivu/releases/latest).
உங்கள் கணினிக்கான கோப்பைத் தேர்ந்தெடுங்கள்:

| கணினி | கோப்பு |
| --- | --- |
| Windows | `Ninaivu-<version>-windows-x64.exe` |
| Apple silicon Mac (M1 மற்றும் அதற்குப் பின்) | `Ninaivu-<version>-macos-arm64.dmg` |
| Intel processor உள்ள Mac | `Ninaivu-<version>-macos-x86_64.dmg` |
| Linux PC | `Ninaivu-<version>-linux-amd64.sh` |
| Raspberry Pi 4 அல்லது 5 (64-bit) | `Ninaivu-<version>-linux-arm64.sh` |

இந்த வழிகாட்டியும் அதே பக்கத்தில் PDF-ஆக, ஆங்கிலத்திலும் தமிழிலும் உள்ளது.

## Windows

`Ninaivu-<version>-windows-x64.exe` கோப்பை இயக்குங்கள். இது உங்கள் கணக்குக்கு
மட்டும் நிறுவப்படும் (நிர்வாகி அனுமதி கேட்காது); தனியான Python-ஐயும்
நினைவுக்குத் தேவையான அனைத்தையும் `%LOCALAPPDATA%\Programs\Ninaivu` கீழ் வைத்து,
Start menu-வில் **Ninaivu**-வைச் சேர்க்கும். *Start Ninaivu at sign-in* என்பதைத்
தேர்ந்தெடுத்தபடியே விட்டால், அது எப்போதும் தயாராக இருக்கும். Start menu-வில் உள்ள
**Ninaivu**-வும், Desktop-இல் உள்ள **Ninaivu Control Panel**-உம் Control Panel-ஐத்
திறக்கும்: Start, Stop, Restart, திறக்க வேண்டிய முகவரிகள், கணினியின் அளவீடுகள், log.
அதே Start menu கோப்புறையில் உள்ள *Ninaivu tray*, system tray-இல் ஒரு சிறிய menu-வை
விரும்புபவர்களுக்கானது.

நிறுவி கையொப்பமிடப்படாவிட்டால் (வெளியீட்டுக் குறிப்புகளில் சொல்லப்பட்டிருக்கும்),
Windows SmartScreen *Windows protected your PC* என்று காட்டும்: **More info → Run anyway**
என்பதைத் தேர்ந்தெடுங்கள்.

[Control Panel, tray பற்றி மேலும் (ஆங்கிலம்).](../../desktop-control.md)

## macOS

உங்கள் Mac-க்கான `.dmg` கோப்பைத் திறங்கள் — Apple silicon-க்கு `arm64`,
Intel-க்கு `x86_64` — பிறகு **Ninaivu**-வை Applications-க்கு இழுத்துவிடுங்கள்.

செயலி notarise செய்யப்படாவிட்டால் (வெளியீட்டுக் குறிப்புகளில் சொல்லப்பட்டிருக்கும்),
முதல் முறை macOS அதைத் திறக்காது. ஒருமுறை திறக்க முயன்று, பிறகு
**System Settings → Privacy & Security** சென்று **Open Anyway** என்பதைத்
தேர்ந்தெடுங்கள்; அதன் பின் வழக்கம்போல் திறக்கும்.

**Ninaivu**-வைத் திறந்தால் Control Panel திறக்கும்: Start, Stop, Restart, திறக்க
வேண்டிய முகவரிகள், கணினியின் அளவீடுகள், log, *Start Ninaivu when I sign in*.
விரும்புபவர்களுக்கு menu-bar tray-உம் உண்டு.

## Linux மற்றும் Raspberry Pi

PC-க்கு `Ninaivu-<version>-linux-amd64.sh`, அல்லது 64-bit OS இயங்கும் Raspberry Pi 4
அல்லது 5-க்கு (வேறு எந்த 64-bit Arm board-க்கும்) `Ninaivu-<version>-linux-arm64.sh`
கோப்பைப் பயன்படுத்துங்கள். அது பதிவிறக்கப்பட்ட கோப்புறையில் ஒரு terminal-ஐத்
திறந்து, இயக்குங்கள்:

```bash
sh Ninaivu-<version>-linux-arm64.sh
```

root தேவையில்லை; கணினியில் Python இருக்க வேண்டியதில்லை: கோப்பு தன் சொந்த Python-ஐயும்,
நினைவு பயன்படுத்தும் ஒவ்வொரு package-ஐயும் உள்ளேயே கொண்டுவருகிறது; எதையும்
பதிவிறக்காது. புகைப்படங்கள் எங்கே என்று ஒருமுறை கேட்டு, உங்கள் கணக்குக்கு நினைவை
நிறுவி, **Ninaivu Control Panel**-ஐ applications menu-விலும் Desktop-இலும் வைத்து,
கணினி தொடங்கும்போது நினைவு தொடங்கவும், நீங்கள் வெளியேறிய பின்னும் இயங்கவும்
அமைத்து, அதைத் தொடங்கி, திறக்க வேண்டிய முகவரியைக் காட்டும்.

## மேம்படுத்துதல்

புதிய நிறுவியை அதே பக்கத்திலிருந்து பதிவிறக்கி, அதே வழியில் நிறுவுங்கள். அது பழைய
நினைவை மாற்றி வைக்கும்; நூலகம், அமைப்புகள், அட்டவணை, நீங்கள் பதிவிறக்கிய AI
மாதிரிகள் அப்படியே இருக்கும்.

!!! note "நினைவை இயக்கும் மற்ற வழிகள்"
    NAS-இல் Docker, source code-இலிருந்து இயக்குதல், command-line options ஆகியவை
    தொழில்நுட்பப் பக்கத்தைக் கவனிப்பவருக்கானவை. அவை
    [தொழில்நுட்ப நிர்வாகி வழிகாட்டியில்](../../admin-guide.md) உள்ளன (ஆங்கிலத்தில்).

## முதலில் நீங்கள் பார்ப்பது

முதல் திரை நிர்வாகியை (administrator) உருவாக்குகிறது. நினைவு இயங்கும் கணினியிலேயே
என்றால் அவ்வளவுதான்; வேறு எந்தச் சாதனத்திலிருந்தும் என்றால், நினைவு தொடங்கிய இடத்தில்
(Control Panel-இன் log, அல்லது terminal-இன் கடைசி வரிகள்) அச்சிடப்பட்ட **setup code**-ஐயும் அது கேட்கும் —
வீட்டில் வேறு யாரும் ஒரு புதிய நூலகத்தை முதலில் கைப்பற்ற முடியாதபடி. `localhost`,
`ninaivu.local` அல்லது கணினியின் சொந்த முகவரி, எதன் வழியாகத் திறந்தாலும் நினைவு இயங்கும்
கணினியில் அது கேட்கப்படாது. நிர்வாகி உருவாகும் வரை அந்தக் குறியீடு நினைவின் state
கோப்புறையில் உள்ள `setup-code.txt`-இலும் இருக்கும் (குறியீட்டை அச்சிடும் வரிகளே அதன் முழுப் பாதையையும் காட்டும்);
மறுதொடக்கத்திலும் அது மாறாது. அதன் பிறகு
நிர்வாக பலகை உங்களை [முதல் நாள்](first-day.md) வழியாக அழைத்துச் செல்லும்.

!!! tip "இரண்டு முகவரிகள்"
    நினைவுக்கு இரண்டு port-களில் இரண்டு முகங்கள் உண்டு: எல்லோரும் நூலகத்தைப்
    பார்க்கும் **குடும்பச் செயலி**, நிர்வாகி அதை நடத்தும் **நிர்வாக பலகை** (console).
    Server பக்கத்தில் வீட்டு network-க்குத் திறக்கும் வரை, நிர்வாக பலகை இந்தக்
    கணினியில் மட்டுமே பதில் அளிக்கும்; குடும்பச் செயலி வீட்டு network முழுவதும்
    கிடைக்கும்.
