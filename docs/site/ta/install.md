# நிறுவுதல்

எப்போதும் இயங்கிக்கொண்டிருக்கும் ஒரு கணினியில் நினைவு இயங்குகிறது: படிக்கட்டுக்குக்
கீழே ஒரு desktop, ஒரு mini PC, ஒரு பழைய laptop, ஒரு Mac mini, Docker இயக்கும் ஒரு
NAS. ஒரு checkout-இலிருந்து இயக்கினால் Python 3.12 அல்லது அதற்குப் புதியது தேவை;
நிறுவிகள் (installers) தங்களுக்கு வேண்டியதைத் தாங்களே கொண்டு வருகின்றன.

## Windows

[சமீபத்திய வெளியீட்டிலிருந்து](https://github.com/javajaga-usa/Ninaivu/releases/latest)
`Ninaivu-<version>-windows-x64.exe` கோப்பைப் பதிவிறக்கி இயக்குங்கள். இது உங்கள்
கணக்குக்கு மட்டும் நிறுவப்படும் (நிர்வாகி அனுமதி கேட்காது); தனியான Python-ஐயும்
நினைவுக்குத் தேவையான அனைத்தையும் `%LOCALAPPDATA%\Programs\Ninaivu` கீழ் வைத்து,
Start menu-வில் **Ninaivu**-வைச் சேர்க்கும். *Start Ninaivu at sign-in* என்பதைத்
தேர்ந்தெடுத்தபடியே விட்டால், அது எப்போதும் தயாராக இருக்கும்.

நிறுவி கையொப்பமிடப்படாவிட்டால் (வெளியீட்டுக் குறிப்புகளில் சொல்லப்பட்டிருக்கும்),
Windows SmartScreen *Windows protected your PC* என்று காட்டும்: **More info → Run anyway**
என்பதைத் தேர்ந்தெடுங்கள். நினைவு winget பட்டியலில் சேர்ந்த பின்
`winget install Ninaivu.Ninaivu` கட்டளையும் வேலை செய்யும்.

**Ninaivu**-வைத் திறந்தால் system tray-இல் ஒரு சின்னம் (icon) தோன்றும். அதன் menu,
server-ஐத் தொடங்கவும் நிறுத்தவும், குடும்பச் செயலியையும் நிர்வாக பலகையையும்
திறக்கவும் உதவும். [Tray பற்றி மேலும் (ஆங்கிலம்).](../../desktop-control.md)

## macOS

உங்கள் Mac-க்கான `.dmg` கோப்பைப் பதிவிறக்குங்கள் — Apple silicon-க்கு `arm64`,
Intel-க்கு `x86_64` —
[சமீபத்திய வெளியீட்டிலிருந்து](https://github.com/javajaga-usa/Ninaivu/releases/latest).
அதைத் திறந்து **Ninaivu**-வை Applications-க்கு இழுத்துவிடுங்கள்.

செயலி notarise செய்யப்படாவிட்டால் (வெளியீட்டுக் குறிப்புகளில் சொல்லப்பட்டிருக்கும்),
முதல் முறை macOS அதைத் திறக்காது. ஒருமுறை திறக்க முயன்று, பிறகு
**System Settings → Privacy & Security** சென்று **Open Anyway** என்பதைத்
தேர்ந்தெடுங்கள்; அதன் பின் வழக்கம்போல் திறக்கும். நினைவு Homebrew-இல் சேர்ந்த பின்
`brew install --cask ninaivu` கட்டளையும் வேலை செய்யும்.

நினைவு Dock-இல் அல்ல, menu bar-இல் இருக்கும். அதன் menu server-ஐத் தொடங்கவும்
நிறுத்தவும், குடும்பச் செயலியையும் நிர்வாக பலகையையும் திறக்கவும், கணினியில்
உள்நுழையும்போதே தானாகத் தொடங்கவும் உதவும்.

## Linux மற்றும் Raspberry Pi

PC-க்கு `Ninaivu-<version>-linux-amd64.sh`, அல்லது 64-bit OS இயங்கும் Raspberry Pi 4
அல்லது 5-க்கு (வேறு எந்த 64-bit Arm board-க்கும்) `Ninaivu-<version>-linux-arm64.sh`
கோப்பை [latest release](https://github.com/javajaga-usa/Ninaivu/releases/latest)
பக்கத்திலிருந்து பதிவிறக்கி, இயக்குங்கள்:

```bash
sh Ninaivu-<version>-linux-arm64.sh
```

root தேவையில்லை; கணினியில் Python இருக்க வேண்டியதில்லை: கோப்பு தன் சொந்த Python-ஐயும்,
நினாவு பயன்படுத்தும் ஒவ்வொரு package-ஐயும் உள்ளேயே கொண்டுவருகிறது; எதையும்
பதிவிறக்காது. புகைப்படங்கள் எங்கே என்று ஒருமுறை கேட்டு, `~/.local/share/ninaivu`-இல்
(`sudo` கொண்டு இயக்கினால் `/opt/ninaivu`-இல்) நிறுவி, `ninaivu` கட்டளையையும் ஒரு
desktop entry-யையும் உருவாக்கி, boot-இல் நினைவைத் தொடங்கி நீங்கள் வெளியேறிய பின்னும்
இயங்க வைக்கும் systemd service-ஐ அமைத்து, தொடங்கி, திறக்க வேண்டிய முகவரியைக் காட்டும்.
SSH வழியாக அமைக்கும் headless Pi-க்கு, `--photos DIR`, `--prefix DIR`, `--no-service`,
`--quiet` ஆகியவை கேள்விகளைத் தவிர்க்கும். புதிய installer-ஐ அதன் மேலேயே இயக்கினால்
மேம்படுத்தப்படும்; நூலகம், அமைப்புகள், அட்டவணை அப்படியே இருக்கும்.
`~/.local/share/ninaivu/uninstall` அதை நீக்கும்.

## Docker

ஒரு NAS அல்லது Linux கணினிக்கு:

```bash
git clone https://github.com/javajaga-usa/Ninaivu.git
cd Ninaivu
cp installers/docker/.env.example installers/docker/.env   # set MEDIA_DIR to your photo folder
docker compose -f installers/docker/docker-compose.yml up -d
```

(`.env` கோப்பில் `MEDIA_DIR` என்பதை உங்கள் புகைப்படக் கோப்புறைக்கு அமையுங்கள்.)

குடும்பச் செயலி port 5000-இல் முழு network-க்கும் பதில் அளிக்கும்; நிர்வாக பலகை
port 3000-இல், NAS-இலேயே மட்டும் (`127.0.0.1:3000`). வேறொரு கணினியிலிருந்து
நிர்வாகியை உருவாக்க, SSH tunnel வழியாகவோ NAS-இலேயோ நிர்வாக பலகையைத் திறந்து,
`docker logs ninaivu`-இல் அச்சிடப்படும் **setup code** (அமைப்புக் குறியீடு) கொடுங்கள்.
`.env` கோப்பு கோப்புறைகளுக்கும் port-களுக்கும் மட்டுமே: நினைவு எப்படி நடந்துகொள்ள
வேண்டும் என்பது அனைத்தும் நிர்வாக பலகையில் தேர்ந்தெடுக்கப்படுகிறது; அடுத்த restart-இல்
`.env`-இல் உள்ள எதுவும் அதை மாற்றாது. `--build-arg WITH_AI=1` உடன் build செய்யாவிட்டால்,
image-இல் விவரித்துத் தேடுதல் (search by description) இருக்காது. systemd, reverse proxy,
HTTPS, பெரிய நூலகங்கள் பற்றி [operations வழிகாட்டி (ஆங்கிலம்)](../../operations/production.md)
விளக்குகிறது.

## ஒரு checkout-இலிருந்து

```bash
git clone https://github.com/javajaga-usa/Ninaivu.git
cd Ninaivu
start.cmd ~/Pictures                 # Windows: or double-click start.cmd
sh launcher/start.sh ~/Pictures      # macOS and Linux
```

Windows-இல் `start.cmd` கோப்பை இருமுறை சொடுக்கினாலும் போதும். Launcher ஒரு
virtual environment உருவாக்கி, இல்லாதவற்றை நிறுவி (பெரியது எதுவும் இல்லை: விவரித்துத்
தேடுதல் வேண்டுமென்றால் பின்னர் சேர்க்கப்படும்), port 443-இல் HTTPS வழங்கி — Linux-இல்
8080, ஏனெனில் அங்கே சாதாரணப் பயனர் 443-ஐப் பயன்படுத்த முடியாது — காலியான port-களைக்
கண்டுபிடித்து, உங்கள் உலாவியைத் திறக்கும்.

server-ஐ நேரடியாக இயக்க:

```bash
python -m ninaivu <folder>
```

இது `--https` கொடுக்காவிட்டால் சாதாரண HTTP-இல், port 80-இல் இயங்கும் (80-ஐப்
பயன்படுத்த உரிமை இல்லையென்றால் 8080).

Windows-இல் `start.cmd`-க்கு முன்பே Python இருக்க வேண்டியதில்லை: Python 3.12 அல்லது
புதியது இல்லை என்று கண்டால், அது முதலில் இந்தப் பயனருக்காக Python 3.12-ஐ நிறுவிவிட்டு
(winget கொண்டு; winget இல்லாவிட்டால் python.org-இலிருந்து) பிறகு தொடரும்.
நிர்வாகி உரிமைகள் தேவையில்லை.

Mac-இல், terminal-ஐப் பயன்படுத்துவதற்குப் பதில், Ninaivu கோப்புறையில் உள்ள **Setup
Ninaivu.command**-ஐ ஒருமுறை இருமுறை சொடுக்குங்கள். அது பதிவிறக்க quarantine-ஐ
நீக்கி, Mac-இல் Python 3.12 அல்லது புதியது இல்லாவிட்டால் Python 3.12-ஐ நிறுவி
(கேட்டுவிட்டு: Mac-இல் Homebrew இருந்தால் அதைக் கொண்டு, இல்லையென்றால்
python.org-இன் installer கொண்டு — அதில் Python Software Foundation-இன் கையொப்பம்
இருந்தால் மட்டுமே அது இயக்கப்படும்; அதற்கு macOS உங்கள் கடவுச்சொல்லைக் கேட்கும்),
நினைவுக்குத் தேவையானவற்றை நிறுவி, Applications-இல் இரண்டு செயலிகளை வைக்கும்:
**Ninaivu** — Terminal சாளரத்தில் நூலகத்தைத் தொடங்கி, உங்கள் புகைப்படங்கள் எந்தக்
கோப்புறையில் உள்ளன என்று ஒருமுறை கேட்கும்; **Ninaivu Control Panel** — terminal
இல்லாமலேயே அதைத் தொடங்கி நிறுத்தும். `sh launcher/start.sh`-உம் இதே Python
நிறுவலை முன்மொழியும். Windows-இல், `start.cmd` ஒருமுறை இயங்கிய பின், **Start -
Ninaivu Control Panel.vbs** Control Panel-ஐத் திறக்கும். [Control Panel பற்றி
மேலும் (ஆங்கிலம்).](../../desktop-control.md)

## முதலில் நீங்கள் பார்ப்பது

முதல் திரை நிர்வாகியை (administrator) உருவாக்குகிறது. நினைவு இயங்கும் கணினியிலேயே
என்றால் அவ்வளவுதான்; வேறு எந்தச் சாதனத்திலிருந்தும் என்றால், நினைவு தொடங்கிய இடத்தில்
(terminal, log, அல்லது `docker logs`) அச்சிடப்பட்ட **setup code**-ஐயும் அது கேட்கும் —
வீட்டில் வேறு யாரும் ஒரு புதிய நூலகத்தை முதலில் கைப்பற்ற முடியாதபடி. அதன் பிறகு
நிர்வாக பலகை உங்களை [முதல் நாள்](first-day.md) வழியாக அழைத்துச் செல்லும்.

!!! tip "இரண்டு முகவரிகள்"
    நினைவுக்கு இரண்டு port-களில் இரண்டு முகங்கள் உண்டு: எல்லோரும் நூலகத்தைப்
    பார்க்கும் **குடும்பச் செயலி**, நிர்வாகி அதை நடத்தும் **நிர்வாக பலகை** (console).
    Server பக்கத்தில் வீட்டு network-க்குத் திறக்கும் வரை, நிர்வாக பலகை இந்தக்
    கணினியில் மட்டுமே பதில் அளிக்கும்; குடும்பச் செயலி வீட்டு network முழுவதும்
    கிடைக்கும்.
