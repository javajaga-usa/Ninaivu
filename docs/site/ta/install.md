# நிறுவுதல்

எப்போதும் இயங்கிக்கொண்டிருக்கும் ஒரு கணினியில் நினைவு இயங்குகிறது: படிக்கட்டுக்குக்
கீழே ஒரு desktop, ஒரு mini PC, ஒரு பழைய laptop, ஒரு Mac mini. எதையும் நிறுவ
வேண்டியதில்லை: நினைவு ஒரே கோப்புறையாக (portable) வருகிறது. அதற்குத் தேவையான
அனைத்தையும் — தன் சொந்த Python-ஐயும் ஒவ்வொரு package-ஐயும் — அது தன்னுடனேயே
கொண்டு வருகிறது; முதலில் வேறு எதையும் நிறுவ வேண்டியதில்லை. கோப்புறையை
நீக்கினால், அது உருவாக்கிய அனைத்தும் நீங்கிவிடும்.

## பதிவிறக்கம்

பதிவிறக்கங்கள் நினைவின் பதிவிறக்கப் பக்கத்தில் உள்ளன:
[github.com/javajaga-usa/Ninaivu/releases/latest](https://github.com/javajaga-usa/Ninaivu/releases/latest).
உங்கள் கணினிக்கான கோப்பைத் தேர்ந்தெடுங்கள்:

| கணினி | கோப்பு |
| --- | --- |
| Windows (64-bit) | `Ninaivu-<version>-windows-x64-portable.zip` |
| Apple silicon Mac (M1 மற்றும் அதற்குப் பின்) | `Ninaivu-<version>-macos-arm64-portable.zip` |
| Linux PC (64-bit: Ubuntu, Debian போன்றவை) | `Ninaivu-<version>-linux-x64-portable.tar.gz` |

இந்த வழிகாட்டியும் அதே பக்கத்தில் PDF-ஆக, ஆங்கிலத்திலும் தமிழிலும் உள்ளது.

கோப்புறையை நீங்கள் எழுதக்கூடிய, இடம் மாறாத ஓர் இடத்தில் வையுங்கள் — உங்கள்
Documents, அல்லது இரண்டாவது disk. நூலகத்தின் அட்டவணை, அமைப்புகள், AI மாதிரிகள்
ஆகியவற்றை நினைவு அதற்குள்ளேயே வைக்கிறது; கோப்புறையை நகர்த்தினாலோ நகலெடுத்தாலோ
அவையும் கூடவே வரும். உங்கள் புகைப்படங்கள் அதற்குள் நகலெடுக்கப்படுவதில்லை: அவை
இருக்கும் இடத்திலேயே இருக்கும்.

## Windows

zip கோப்பை வலது-click செய்து **Extract All** தேர்ந்தெடுங்கள்; அது உருவாக்கும்
கோப்புறையில் உள்ள **Ninaivu.exe**-ஐத் திறங்கள். Control Panel திறக்கும்: Start,
Stop, Restart, திறக்க வேண்டிய முகவரிகள், கணினியின் அளவீடுகள், log, *Start Ninaivu
when I sign in*. system tray-இல் ஒரு சிறிய menu-வை விரும்புபவர்களுக்கு அதுவும் உண்டு.

Ninaivu.exe கையொப்பமிடப்படாவிட்டால் (வெளியீட்டுக் குறிப்புகளில் சொல்லப்பட்டிருக்கும்),
Windows SmartScreen *Windows protected your PC* என்று காட்டும்: **More info → Run anyway**
என்பதைத் தேர்ந்தெடுங்கள்.

[Control Panel, tray பற்றி மேலும் (ஆங்கிலம்).](../../desktop-control.md)

## macOS

zip கோப்பை இருமுறை click செய்து, அது உருவாக்கும் **Ninaivu** கோப்புறையை உங்கள்
Documents-க்கு (அல்லது ஒரு drive-க்கு) நகர்த்தி, அதற்குள் உள்ள **Ninaivu.app**-ஐத்
திறங்கள்.

செயலி notarise செய்யப்படாவிட்டால் (வெளியீட்டுக் குறிப்புகளில் சொல்லப்பட்டிருக்கும்),
முதல் முறை macOS அதைத் திறக்காது. ஒருமுறை திறக்க முயன்று, பிறகு
**System Settings → Privacy & Security** சென்று **Open Anyway** என்பதைத்
தேர்ந்தெடுங்கள்; அதன் பின் வழக்கம்போல் திறக்கும். macOS ஒரு தற்காலிக நகலிலிருந்து
திறந்ததாக நினைவு சொன்னால், Terminal-ஐத் திறந்து `xattr -dr com.apple.quarantine `
(இறுதியில் ஓர் இடைவெளியுடன்) என்று தட்டச்சு செய்து, Ninaivu கோப்புறையை அந்தச்
சாளரத்தின் மேல் இழுத்துவிட்டு, Return அழுத்தி, மீண்டும் திறங்கள்.

**Ninaivu**-வைத் திறந்தால் Control Panel திறக்கும்: Start, Stop, Restart, திறக்க
வேண்டிய முகவரிகள், கணினியின் அளவீடுகள், log, *Start Ninaivu when I sign in*.
விரும்புபவர்களுக்கு menu-bar tray-உம் உண்டு.

## Linux

அது பதிவிறக்கப்பட்ட கோப்புறையில் ஒரு terminal-ஐத் திறந்து, பிரித்தெடுத்துத்
தொடங்குங்கள்:

```bash
tar -xzf Ninaivu-<version>-linux-x64-portable.tar.gz
cd Ninaivu-<version>-linux-x64-portable
./ninaivu
```

root தேவையில்லை; கணினியில் Python இருக்க வேண்டியதில்லை: கோப்புறை தன் சொந்த
Python-ஐயும், நினைவு பயன்படுத்தும் ஒவ்வொரு package-ஐயும் உள்ளேயே கொண்டுவருகிறது;
எதையும் பதிவிறக்காது. `./ninaivu` Control Panel-ஐத் திறக்கும். desktop இல்லாத
கணினியில் (ஒரு server, அல்லது ssh வழியாக), `./ninaivu --server ~/Pictures` அந்த
terminal-இலேயே `~/Pictures`-ஐ நூலகமாகக் கொண்டு நினைவை இயக்கும்; கணினி தொடங்கும்போதே
அது தொடங்க வேண்டுமென்றால், தொழில்நுட்ப நிர்வாகி வழிகாட்டியில் "The Linux system
service" பகுதியைப் பாருங்கள்.

## மேம்படுத்துதல்

புதிய பதிப்பு உள்ளதா என்று நினைவு இணையத்தில் தேடுவதில்லை. புதிய பதிப்பு
வேண்டும்போது, புதிய கோப்பை அதே பக்கத்திலிருந்து பதிவிறக்குங்கள்.

புதிய பதிப்பைப் **பழைய கோப்புறைக்கு அருகில், அதே டிரைவில்** ஒரு புதிய கோப்புறையில்
பிரித்தெடுத்து, அதைத் திறங்கள் (`Ninaivu.exe`, `Ninaivu.app` அல்லது `./ninaivu`).
அதன் Control Panel பழைய கோப்புறையைக் கண்டுபிடித்து, உங்கள் நூலகத்தை இங்கே கொண்டுவரலாமா
என்று கேட்கும். ஆம் என்று சொல்லுங்கள்: பழைய நினைவு இயங்கிக்கொண்டிருந்தால் அதை நிறுத்தி,
நூலகம், அமைப்புகள், AI மாதிரிகள் ஆகியவற்றைப் புதிய கோப்புறைக்கு நகர்த்தும். எதுவும்
நகலெடுக்கப்படுவதில்லை, அதனால் நூலகம் எவ்வளவு பெரியதாக இருந்தாலும் ஒரு கணத்தில் முடியும்.
பிறகு **Start** அழுத்துங்கள். ஒவ்வொரு கோப்புறையிலும் உள்ள `README-PORTABLE.txt`-உம்
இதையே சொல்கிறது.

**மேம்படுத்தல் உங்கள் புகைப்படங்களைத் தொடவே தொடாது.** அமைப்புகள், அட்டவணை (பெயர்கள்,
ஆல்பங்கள், முகங்கள், பகிர்வு இணைப்புகள்), குடும்பத்தினரின் கணக்குகள், நீங்கள்
பதிவிறக்கிய AI மாதிரிகள் எல்லாம் புதிய கோப்புறைக்குச் செல்லும். பழைய கோப்புறையில் அதன்
நிரலும், நூலகம் எங்கே சென்றது என்று சொல்லும் `LIBRARY-MOVED.txt` குறிப்பும் இருக்கும்.

மனம் மாறினால், புதிய Control Panel-இல் உள்ள **Go back to …** எல்லாவற்றையும் பழைய
பதிப்பு விட்டுச்சென்றபடியே பழைய கோப்புறைக்குத் திருப்பி நகர்த்தும்; பழைய கோப்புறையை
நீங்கள் வைத்திருக்கும் வரை இது செய்யமுடியும். புதிய பதிப்பு உங்கள் கணினியில் தொடங்கவே முடியவில்லை என்றால், இரண்டாவது முயற்சிக்குப் பின் இதைத் தானாகவே செய்து பழையதைத் திறக்கும்.

புதிய பதிப்பு முதல் முறை தொடங்கும்போது, எதையும் மாற்றுவதற்கு முன் அமைப்புகளையும்
அட்டவணையையும் ஒரு நகலாகச் சேமித்து, பிறகு வழக்கம்போல் தொடங்கும். பழைய பதிப்புக்கு
அதன் அட்டவணையை அது விட்டுச்சென்றபடியே தர **Go back** அந்த நகலைப் பயன்படுத்துகிறது
([தொழில்நுட்ப நிர்வாகி வழிகாட்டியில்](../../admin-guide.md), "Updating to a new
version" பகுதி மேலும் சொல்கிறது).

!!! note "நினைவை இயக்கும் மற்ற வழிகள்"
    NAS-இல் Docker, source code-இலிருந்து இயக்குதல், command-line options ஆகியவை
    தொழில்நுட்பப் பக்கத்தைக் கவனிப்பவருக்கானவை. அவை
    [தொழில்நுட்ப நிர்வாகி வழிகாட்டியில்](../../admin-guide.md) உள்ளன (ஆங்கிலத்தில்).

## முதலில் நீங்கள் பார்ப்பது

முதல் திரை நிர்வாகியை (administrator) உருவாக்குகிறது. நினைவு இயங்கும் கணினியிலேயே
என்றால் அவ்வளவுதான்; வேறு எந்தச் சாதனத்திலிருந்தும் என்றால், நினைவு தொடங்கிய இடத்தில்
(Control Panel-இன் log, அல்லது terminal-இன் கடைசி வரிகள்) அச்சிடப்பட்ட **setup code**-ஐயும் அது கேட்கும் —
வீட்டில் வேறு யாரும் ஒரு புதிய நூலகத்தை முதலில் கைப்பற்ற முடியாதபடி. `localhost`,
`ninaivu.local` அல்லது கணினியின் சொந்த முகவரி, எதன் வழியாகத் திறந்தாலும் நினைவு இயங்கும்
கணினியில் அது கேட்கப்படாது. நிர்வாகி உருவாகும் வரை அந்தக் குறியீடு நினைவின் state
கோப்புறையில் உள்ள `setup-code.txt`-இலும் இருக்கும் (குறியீட்டை அச்சிடும் வரிகளே அதன் முழுப் பாதையையும் காட்டும்);
மறுதொடக்கத்திலும் அது மாறாது. அதன் பிறகு
நிர்வாக பலகை உங்களை [முதல் நாள்](first-day.md) வழியாக அழைத்துச் செல்லும்.

!!! tip "இரண்டு முகவரிகள்"
    நினைவுக்கு இரண்டு port-களில் இரண்டு முகங்கள் உண்டு: எல்லோரும் நூலகத்தைப்
    பார்க்கும் **குடும்பச் செயலி**, நிர்வாகி அதை நடத்தும் **நிர்வாக பலகை** (console).
    Server பக்கத்தில் வீட்டு network-க்குத் திறக்கும் வரை, நிர்வாக பலகை இந்தக்
    கணினியில் மட்டுமே பதில் அளிக்கும்; குடும்பச் செயலி வீட்டு network முழுவதும்
    கிடைக்கும்.
