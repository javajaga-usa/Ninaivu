# சிக்கல் தீர்த்தல்

## கைப்பேசியில் நினைவு திறக்கவில்லை

- கைப்பேசி mobile data-வில் அல்ல, வீட்டு Wi-Fi-இல் இருக்க வேண்டும்.
- நிர்வாக பலகையின் **Server** பக்கம் *for the household* என்பதன் கீழ் பட்டியலிடும்
  முகவரியைப் பயன்படுத்துங்கள். `localhost` server-இல் மட்டுமே வேலை செய்யும்.
- Server பக்கத்தில் **Network access** இயக்கத்தில் இருக்க வேண்டும்; அணைந்திருந்தால்
  நினைவு server-இல் மட்டுமே பதில் அளிக்கும். அதை இயக்கியபின் restart தேவை.
- Windows: firewall அதைத் தடுத்தால், port-களைத் திறக்கும் இரண்டு `netsh` கட்டளைகளைத்
  தொடக்க log அச்சிடும்; administrator ஆகத் திறந்த ஒரு terminal-இல் அவற்றை ஒருமுறை
  இயக்குங்கள்.

## என் laptop-இலிருந்து நிர்வாக பலகையைத் திறக்க முடியவில்லை

Server பக்கத்தில் (அந்தக் கணினியிலேயே) *Open this console from other devices at home
too* என்பதைத் தேர்ந்தெடுக்கும் வரை, நிர்வாக பலகை நினைவு இயங்கும் கணினியில் மட்டுமே
பதில் அளிக்கும். நினைவு restart ஆகும்; அதன் பிறகு நிர்வாக பலகை வீட்டு network-இலும்
கிடைக்கும்.

## உலாவி சான்றிதழ் பற்றி எச்சரிக்கிறது

நினைவு தன் சொந்த certificate authority-உடன் HTTPS வழங்குகிறது. ஒவ்வொரு சாதனத்திலும்
அதை ஒருமுறை நம்புங்கள் (trust): tray-இன் **Trust the HTTPS certificate**, அல்லது
Server பக்கத்தின் பொத்தான்; Windows, macOS-இல் கையால் செய்வதற்கு
[tray பக்கம் (ஆங்கிலம்)](../../desktop-control.md). அல்லது முன்னால் Tailscale அல்லது
ஒரு reverse proxy வையுங்கள் — அவை தங்கள் சொந்தச் சான்றிதழ்களைக் கொண்டு வருகின்றன.

## கோப்புறையைத் தேர்ந்தெடுத்த பின் எதுவும் தெரியவில்லை

நூலகம் பின்னணியில் அட்டவணைப்படுத்தப்படுகிறது; பெரியதாக இருந்தால் சற்று நேரம் ஆகும்.
Overview-இன் **Library** எண்களும், Server பக்கத்தின் log-உம் அது நடப்பதைக் காட்டும்.
கோப்புறை இணைக்கப்படாத ஒரு வட்டில் இருந்தால், எதுவும் காட்டாமல் இருப்பதற்குப் பதிலாக
படத்தொகுப்பே அதைச் சொல்லும்.

## ஸ்கேன் மெதுவாக இருக்கிறது

**System → Performance** இந்தக் கணினி என்ன செய்ய முடியும், எது உதவும் என்று சொல்லும்.
சிறிய கணினியில், தேவையில்லாத சுற்றுகளை **AI models**-இல் அணையுங்கள் (புகைப்படங்களில்
எழுத்துகளும் காணொளித் தருணங்களும்தான் செலவானவை), அல்லது குடும்பத்தினர் கணினியைப்
பயன்படுத்தும்போது Server பக்கத்தில் *power-saving* தேர்ந்தெடுங்கள். ஸ்கேனை நிறுத்தலாம்;
அது நிறுத்திய இடத்திலிருந்தே மீண்டும் தொடரும்.

## ஒரு model பதிவிறக்கம் ஆகவில்லை

Model-கள் GitHub, Hugging Face-இலிருந்து வருகின்றன. பதிவிறக்கும் நேரத்தில் கணினிக்கு
இணைய இணைப்பு இருக்கிறதா என்று பாருங்கள்; எந்தக் கோப்பு தோல்வியடைந்தது என்று AI
models பக்கம் சொல்லும். ஒரு model இங்கே வந்துவிட்டால், அதன் பிறகு இணையத்திடம்
எதுவும் கேட்கப்படாது.

## நகல் மீட்டெடுக்கப்படவில்லை என்று முகில் சொல்கிறது

வாராந்திரச் சோதனை சில கோப்புகளைத் திரும்பக் கொண்டு வந்து ஒப்பிடுகிறது. அது
தோல்வியடைந்தால், எந்தக் கோப்பு, ஏன் என்று **Mugil → Test restores** சொல்லும்;
வழக்கமான காரணங்கள்: மாற்றப்பட்ட Google கடவுச்சொல் (Mugil-இல் மீண்டும் உள்நுழையுங்கள்),
நிரம்பிய Drive.

## எதுவும் பதிவேற்றப்படவில்லை என்று முகில் சொல்கிறது

மறையாக்கம் இயல்பாக இயக்கத்தில் இருக்கும்; மறையாக்க விசை உருவாகும் வரை எதுவும்
பதிவேற்றப்படாது. Mugil பக்கத்தில் அதை உருவாக்கி, மீட்பு கோப்பைப் பத்திரமாக வையுங்கள்.

## நினைவு தொடங்கவில்லை

காரணம் Control Panel-இல் உள்ள log-இல் (அல்லது tray-இன் **View the log**-இல்)
இருக்கும். பொதுவானவை: port-ஐ வேறொரு நிரல் எடுத்துக்கொண்டிருக்கிறது (அப்போது
நினைவு அடுத்த காலியான port-க்கு மாறி அதைச் சொல்லும்), state கோப்புறை mount
செய்யப்படாத ஒரு வட்டில் உள்ளது, அல்லது அதே state கோப்புறையிலிருந்து இன்னொரு
நினைவு ஏற்கனவே இயங்குகிறது.

## வேறொரு கணினிக்கு மாறுதல்

**System → Move to another computer** ஒரு நிறுவலை உருவாக்கும் மூன்று விஷயங்களைப்
பட்டியலிடுகிறது; புதிய கணினியில், நூலகம் எங்கே வந்து சேர்ந்ததோ அதை நோக்கி,
மீண்டும் அட்டவணைப்படுத்தாமலேயே, அட்டவணையைத் திருப்புகிறது.
[விவரங்கள் (ஆங்கிலம்).](../../moving-to-another-machine.md)

## உதவி பெறுதல்

உங்கள் நினைவைக் கவனித்துக்கொள்பவரிடம் கேளுங்கள்; சிக்கலை எங்கே தெரிவிப்பது என்று
[தொழில்நுட்ப நிர்வாகி வழிகாட்டி](../../admin-guide.md) சொல்கிறது. எந்தப் பதிப்பு
(**System → Settings** அதை *This home* கீழ் காட்டும்), நீங்கள் என்ன செய்தீர்கள், log என்ன சொன்னது என்று
குறிப்பிடுங்கள்.
