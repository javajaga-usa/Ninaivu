# Creative Studio

Open a photo in the main picture viewer, choose **AI Playground**, and select
**Creative Studio · albums, collages & more** in the editing tools. The studio
receives the original and your adjusted photo. Additional photos come from the
**Add photos** picker; they stay in your browser and are not uploaded.

| Creation | Controls and output |
| --- | --- |
| Restoration story | Original/edited slider; download an interactive HTML story. |
| Family story album | Up to 12 photos, individual dates/captions, a shared story, and an optional audio recording; download a complete HTML album. |
| Photo postcard | Title, message and background color; PNG or browser print. |
| Collage studio | Reorder photos, choose columns, spacing and background; PNG or print. |
| Then & now | Add a second photo; align it using zoom and horizontal/vertical position; export the interactive slider. |
| Cinematic slideshow | Captions, gentle motion, duration, previous/next and play/pause; optional music; export an offline HTML presentation. |
| Selective color | Brush color back into a monochrome photo; erase or undo strokes; PNG. Keyboard users can move the brush with arrows and paint with Space. |
| Creative versions | Keep up to 11 named looks in the open workspace, export a comparison sheet, or download the current look individually. |
| Recipe memories | Dish photo, story, ingredients and directions; PNG or print. |
| Photo calendar | Choose a month and add occasions as `day — event`; PNG or print, one month at a time. |

HTML exports include their images and attached audio, so they can be opened
offline in a browser. Playback starts when the recipient presses Play; audio
formats must be supported by that browser. Attach an existing voice recording
or music file using the audio picker (up to 15 MB). The studio does not record
from the microphone or generate music.

Photos are resized to at most 1,600 pixels per side in this workspace. PNG
layouts are 1,440 × 1,080, or 1,440 × 1,800 for recipes and calendars. The normal
AI Playground export remains the option for full-resolution edited photos.
Layout photos use centered crops; inspect the preview before exporting. Long
text may exceed a fixed PNG layout; shorten it or use an HTML album for long
stories. Print / save PDF opens the browser's print dialog.

Creations and versions remain in memory until you close the studio. **Download
before closing.** Closing with changes asks for confirmation. Downloads contain
the pictures, captions and audio you deliberately include, so share them only
with the intended recipients. No library files are overwritten.
